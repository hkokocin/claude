# Update Check

* Determine which libraries were updated.
* Read every release note from the current to the new version for breaking changes and deprecations.
* Check whether they affect the code; where they do, find how to address them (code or configuration changes).
* Summarise the findings and assess the impact of resolving the breaking changes.
